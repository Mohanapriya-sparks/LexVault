## 2. Reporting a Vulnerability

We take cryptographic and smart-contract security seriously. If you discover a security vulnerability or cryptographic flaw in LexVault:

1. **Do not open a public GitHub issue.**
2. Please email the maintainers at `security@lexvault.io` (or reach out via confidential GitHub Security Advisory).
3. Include details of the vulnerability, proof of concept, and affected components (e.g., Circom circuit, smart contracts, Shamir reconstruction).
4. We will acknowledge receipt within 48 hours and work with you on a coordinated fix.

---

## 3. Prototype Scope Disclaimer

LexVault is an open-source research and hackathon prototype demonstrating zero-knowledge evidence custody. It has not undergone formal third-party audit and should not be deployed in critical legal proceedings without independent security evaluation.
